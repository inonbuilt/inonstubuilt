About SPOM Set A, Set B, Set C & Set D Mock Tests

The Self-Paced Online Module (SPOM) Mock Tests provided by Calcium Notes are designed to help CA students prepare effectively for the ICAI examination. Our mock tests follow the latest ICAI pattern and provide a real exam experience with objective-type MCQs, instant evaluation, and detailed performance analysis.

Students can practice multiple SPOM Sets and improve their speed, accuracy, conceptual understanding, and confidence before appearing for the actual examination.

Every question is carefully prepared based on the latest ICAI syllabus and updated whenever ICAI introduces new concepts or amendments.

Calcium Notes aims to provide completely free, high-quality SPOM preparation resources for CA students including Notes, Mock Tests, Practice Questions, Case Scenario MCQs and Performance Analysis.

Focusing on SPOM Set C (Elective Modules): While Set A and Set B test your knowledge on mandatory core subjects, Set C offers a unique challenge by allowing you to specialize in your preferred elective domain. Our Set C Mock Tests are specifically tailored to cover the vast and diverse syllabus of these specialized subjects, including highly analytical areas like Forensic Accounting, Risk Management, and International Taxation.

Because Set C electives demand a high level of practical application, our mock exams heavily feature complex, integrated case-scenario MCQs. These scenario-based questions are engineered to test your critical thinking and professional judgment, replicating the exact difficulty, time constraints, and environment of the official ICAI portal.

Mastering a specialized Set C module requires deep conceptual clarity and continuous practice. To help you conquer these electives, Calcium Notes breaks down heavy modules into digestible practice sessions. You get unlimited access to topic-wise quizzes and full-length 100-mark simulated exams, allowing you to easily identify weak areas, improve your score, and confidently secure the required 50% passing criteria.
